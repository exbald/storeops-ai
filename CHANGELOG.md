# Specification history

## 2.0.0

Replaces the demo-led technical outline with an empty-state application contract. Adds
normal data-entry/import workflows, policy review, durable jobs, operational persistence,
strict public and agent interfaces, error/state semantics, 15 assignable tasks and 41
acceptance cases. Separates test factories, live evaluations and optional demo seed.

Gemini 3.8 Flash remains primary. Model quality targets are not measured results.
No application implementation, cloud deployment or live model evaluation is included
in this specification release.
